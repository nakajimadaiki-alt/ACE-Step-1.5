現状の「文字とインプットが縦に並んでいるだけ」の状態から、**「モダンな動画編集ソフト（DaVinci ResolveやCapCut Webのような）」**風のUIに刷新する案を提案します。

既存のReact + Vite構成を活かしつつ、CSSとレイアウト構造を変更するだけで劇的に改善できます。

---

# UI刷新コンセプト: "Modern Dark Studio"

## 1. 全体レイアウトの再設計

画面を3つのエリアに分割します。

| エリア | 役割 | 改善ポイント |
|:---:|:---|:---|
| **左サイドバー (Sidebar)** | **シーン選択** | アイコン付きのメニューリストにし、常に表示する。 |
| **中央・下 (Main & Timeline)** | **プレビュー & 再生** | 画面中央に大きくプレビューを表示。その直下にタイムライン（シークバー）を配置。 |
| **右パネル (Inspector)** | **詳細設定 & 操作** | 現在選択中のシーンに応じた「設定項目（画像選択、円盤設定、テキスト入力）」をここに集約。 |

### レイアウトイメージ (Wireframe)

```
+---------------------------------------------------------------+
| HEADER (ロゴ + エクスポートボタン)                             |
+-------+-----------------------------------+-------------------+
|       |                                   |                   |
| SCENE |           PREVIEW AREA            |     INSPECTOR     |
| LIST  |      (Canvasを中央に配置)          |   (設定パネル)     |
|       |                                   |                   |
| [img] |                                   |  [ シーン設定 ]    |
| [vid] |                                   |  画像: [Dropzone] |
| [auto]|                                   |  X位置: O-----|   |
| [disc]|                                   |  Style: (A) (B)   |
|       |                                   |                   |
+-------+-----------------------------------+-------------------+
|           TIMELINE (再生/停止, ルーラー, シークバー)            |
+---------------------------------------------------------------+
```

## 2. 具体的な改善案 (コンポーネント別)

### A. 全体テーマ (Color Palette)

動画編集ソフトの定番である**ダークモード**を採用します。コンテンツ（動画）を目立たせるためです。

* **背景**: `#1e1e1e` (ダークグレー)
* **パネル背景**: `#252526` (少し明るいグレー)
* **アクセント**: `#3b82f6` (鮮やかなブルー / 選択状態やボタン)
* **テキスト**: `#e4e4e7` (白に近いグレー)
* **境界線**: `#3f3f46`

### B. シーン選択 (左サイドバー)

テキストの箇条書きをやめ、**アイコン + ラベル**のボタンスタイルにします。

* **Before:** `シーン選択` `静止画表示` `円盤回転` ...
* **After:**
  * 📂 **静止画** (Static)
  * 💿 **円盤** (Disc)
  * 🎬 **再現** (Template)
  * ✨ **演出** (Auto)
  * 選択中のアイテムは背景を青くし、右端にインジケーターを表示。

### C. 設定パネル (右パネル・インスペクター)

入力項目をただ並べるのではなく、グループ化します。

1. **ファイル選択**: `<input type="file">` を隠し、点線枠の **「ドラッグ＆ドロップエリア」** に変更。プレビュー画像を表示。
2. **スライダー**: HTML標準の見た目をやめ、細いラインと丸いつまみのカスタムCSSを適用。数値入力を隣に配置。
3. **スタイル切替**: ラジオボタンではなく、**カード型の選択肢**（図解付き）にして、クリックで選べるようにする（例：シンプル円盤 vs レコード盤のイラストを並べる）。

### D. プレビューとタイムライン

* **プレビュー**: 背景に「市松模様（チェッカー）」を敷き、透過部分がわかるようにする。ドロップシャドウをつけて「浮いている」感を出す。
* **タイムライン**:
  * 再生ボタンを大きく中央に配置。
  * 現在の時間を `00:00:05 / 00:00:30` のようにデジタル時計フォントで表示。
  * シークバーを太くし、ホバー時にタイムコードが出るようにする。

## 4. UIコンポーネント実装のヒント (React)

もしデザインに時間をかけすぎたくない場合は、既存のUIライブラリを導入するのが手っ取り早いです。

### おすすめライブラリ

1. **Shadcn/UI (Radix UI + Tailwind)**:
    * 現在のReact界隈で最も人気のスタイル。
    * スライダー、セレクトボックス、アコーディオンなどがコピー＆ペーストで実装可能。
    * 「モダンでミニマル」な見た目が即座に手に入ります。

2. **Mantine**:
    * フックやコンポーネントが非常に豊富。`<Slider />`, `<FileButton />`, `<AppShell />` など動画編集UIに必要なパーツが全部揃っています。

### 独自実装する場合の修正箇所

現在の `Editor.jsx` の構造を以下のように変更してください。

```jsx
// Editor.jsx の構造イメージ
return (
  <div className="editor-container">
    {/* 左: シーン選択 */}
    <aside className="sidebar">
      <div className="logo">VideoMaker</div>
      <nav>
        <button onClick={() => setScene('static')} className={scene === 'static' ? 'active' : ''}>
           🖼 静止画
        </button>
        <button onClick={() => setScene('disc')} className={scene === 'disc' ? 'active' : ''}>
           💿 円盤回転
        </button>
        {/* ...他シーン */}
      </nav>
    </aside>

    {/* 中央: プレビュー */}
    <main className="preview-area">
      <div className="canvas-wrapper">
        <Preview scene={scene} frame={currentFrame} ... />
      </div>
    </main>

    {/* 右: 設定 (Inspector) */}
    <aside className="inspector">
      {/* シーンごとに表示内容を切り替え */}
      {scene === 'disc' && (
        <div className="properties">
          <h3>円盤設定</h3>
          
          <div className="input-group">
            <label>スタイル</label>
            <div className="style-selector">
              <button onClick={() => setStyle('simple')}>シンプル</button>
              <button onClick={() => setStyle('vinyl')}>レコード</button>
            </div>
          </div>

          <div className="input-group">
            <label>画像位置 X ({offsetX}%)</label>
            <input type="range" min="0" max="100" value={offsetX} ... />
          </div>
          
          {/* エクスポート設定もここに含める */}
          <div className="export-section">
             <button className="btn-primary" onClick={handleExport}>
               MP4書き出し
             </button>
          </div>
        </div>
      )}
    </aside>

    {/* 下: タイムライン */}
    <footer className="timeline-panel">
      <button onClick={togglePlay}>{isPlaying ? '⏸' : '▶'}</button>
      <input type="range" className="scrubber" value={currentFrame} max={totalFrames} ... />
      <span className="time-display">{formatTime(currentFrame)}</span>
    </footer>
  </div>
);
```

この構成にするだけで、現在の「プロトタイプ感」が消え、「ツール」としての完成度が上がります。
